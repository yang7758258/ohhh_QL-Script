## 一、三十秒上手

**只需要填一个变量：**

```bash
unicom = 18500000000:你的登录密码
```

建定时任务：`task unicom_signin.js`，建议 `45 8 * * *`。完事。

> 脚本会自己登录、拿 token、签到、做任务。token 失效了也会自己重新登录，
> 不需要抓包、不需要手动维护。

多账号换行写：

```bash
unicom = 18500000000:密码1
         18600000000:密码2
```

> ⚠️ 这里要的是 **App 的登录密码**（手机上登录联通 App 那个），
> 不是「服务密码」。两者不同，服务密码会返回 `code 11`。
>
> ⚠️ 全自动登录需要运行环境具备：**Chrome/Chromium + Node + Python3 + Playwright**。
> 部署方式见「六、自动续期怎么布」。

## 三、账号密码登录：可以全自动（已实测跑通）

> 早期版本这里写的是「密码登录走不通，别浪费时间」。**那句话是错的**，已修正。

密码登录确实要过腾讯点选验证码，但**用真实浏览器点一下就能过**，不需要在
Python 里复现腾讯的 `collect` / `eks` / `pow_answer` 加密参数。

完整链路（`unicom_auto_login.py` 实现，全自动，实测 14~98 秒完成）：

```
① POST loginhl.10010.com/mobileService/login.htm
   mobile   = RSA_PKCS1_v1_5(手机号 + 6位随机数)
   password = RSA_PKCS1_v1_5(密码   + 6位随机数)
   → code=ECS99999 + mobile(640 hex) + type=10

② 真实浏览器打开 loginRisk，注入腾讯 TCaptcha（aid=195809716）
   抓提示条(img_index=0) + 背景图(img_index=1)
   连通域∪AntiCAP 检测图标 → 旋转不变 IoU 匹配顺序 → 真实鼠标按序点击 → 点「确定」
   → ticket + randstr（整个过程腾讯 SDK 自己算完所有加密参数）

③ POST loginhl.10010.com/login-web/v1/chartCaptcha/validateTencentCaptcha
   明文 JSON：{"seq","captchaType":"10","mobile","ticket","randStr","imei"}
   （encrypt-key / scene-key 两个头保持空字符串，不需要任何 AES 加密）
   → resultToken

④ POST login.htm 带上 resultToken
   → code=0 + ecs_token ✅
```

**为什么必须用浏览器**：`cap_union_new_verify` 的 `collect` 是 tdc.js 用 Canvas/
浏览器指纹 + 鼠标轨迹加密出来的，纯 Python 补不出来。而只要在 iframe 里用
**真实鼠标**点对坐标（`page.mouse.move/down/up`，带轨迹和停顿），SDK 就会
自己算好并提交。

### 什么时候会用到自动登录？

| 情况 | 处理 |
|---|---|
| token 还有效（≥25.5 小时实测） | 直接签到，不触发登录 |
| token 失效（返回 `0001`） | 自动用密码登录换新 token，**并回写青龙**，然后继续签到 |
| 登录需要浏览器环境 | 打印提示，可用 token 模式兜底 |

开启方式：**只需要一个变量**。

```bash

```

多账号换行：

```bash
unicom = 18500000000:密码1
         18600000000:密码2
```

> ⚠️ 这里要 **App 登录密码**，不是服务密码。服务密码会返回 `code 11`。
> ⚠️ 还需要 Chrome + Python3 + Playwright，见「六、自动续期怎么布」。

## 五、失效了怎么办

**正常情况（推荐）**：什么都不用做。脚本自己识别 token 失效，自动过验证码
重新登录，换到新 token，回写青龙，然后继续签到。日志长这样：

```
│  🔄 尝试密码自动登录：185****8363
│  ✅ 自动登录成功（14s），已换到新 ecs_token
│  ☁  青龙已同步新 token
│  🗝  token eyJkYXRh…IwMCJ9  联通在网 ✅
│  📅 连签 0 天   今日已签 ✅
```

**登录失败**（风控拦截，返回 `code=2` 要求短信验证）：

```
│  🔑 自动登录失败
└─ 请检查密码是否正确，或稍后重试
```

处理：等几小时或换个网络（如手机热点）再跑一次，风控会自解。
这个和密码对不对无关，是账号维度的临时闸门。

> **token 实测寿命 ≥25.5 小时**：10-25 20:16 拿到的 token，到 10-26 21:44 仍返回
> `status=0000` 能正常签到。所以每天跑一次任务，正常情况下根本不会失效。

## 六、自动续期怎么布（三种落地方式）

自动续期需要 **Chrome/Chromium + Node + Python3 + `requests`/`pycryptodome`/`Pillow`/`numpy` + `playwright-core`**。
青龙容器默认没有浏览器，所以要选一种方式：

### 方案 A：Windows 本机跑（最简单，推荐）

青龙只负责签到（纯 HTTP，无依赖），Windows 本机定时任务负责「token 续期 + 回写青龙」。

1. 本机装好 Node 20 / Python 3.8+ / Chrome，然后在**脚本所在目录**执行：
   ```powershell
   npm install playwright-core
   pip install requests pycryptodome pillow numpy
   ```

### 方案 B：直接在青龙容器里跑（★ 实测可行，推荐）

青龙镜像本身**已经带了 `chrome-headless-shell`**，不用另装浏览器：

```bash
/ql/scripts/chrome/chrome-headless-shell-linux64/chrome-headless-shell
# Google Chrome for Testing 139.0.7258.154
```

实测环境（Debian 12 / Python 3.11 / Node 20 / 内存 1.7G）：

| 项目 | 状态 |
|---|---|
| `chrome-headless-shell` | ✅ 自带 |
| `python` / `python3` | ✅ 自带 |
| `node` / `npm` | ✅ 自带 |
| `requests` / `pycryptodome` / `pillow` / `numpy` | ❌ 需补装 |
| `playwright-core`（npm） | ❌ 需补装 |

**一次性补齐**（注意必须用国内源，直连 PyPI 会 ReadTimeout）：

```bash
# Python 包（阿里云源）
pip3 install --no-cache-dir \
  -i https://mirrors.aliyun.com/pypi/simple/ \
  --trusted-host mirrors.aliyun.com \
  requests pycryptodome pillow numpy

# Node 模块
mkdir -p /ql/data/scripts/unicom_auto
cd /ql/data/scripts/unicom_auto
npm init -y
npm install --no-audit --no-fund playwright-core
```

> 💡 `unicom_auto_login.py` 已内置**依赖自愈**：检测到缺包会自动用阿里云源补装，
> 所以青龙容器重建后不用手动处理，直接跑就行。

**实测结果**：容器内登录耗时约 37 秒，签到全流程正常。
内存峰值约 1.3G / 1.7G，够用但别同时跑太多任务。
